# ledtwo.github.io — 个人博客

Personal blog / 个人博客，访问地址：https://ledtwo.github.io

## 说明

本站为 Hexo 生成的静态站点产物，包含文章归档（`2020/`）、分类（`categories/`）、标签（`tags/`）、关于（`about/`）等页面。

This repo holds the generated static output of a Hexo-powered personal blog.

## 目录

- `2020/` — 文章页面 / posts
- `about/` — 关于页面 / about
- `archives/` — 归档 / archives
- `categories/` — 分类 / categories
- `tags/` — 标签 / tags
- `links/` — 友链 / links
- `css/` `js/` `images/` `fancybox/` — 静态资源 / static assets

直接打开 `index.html` 即可浏览。
